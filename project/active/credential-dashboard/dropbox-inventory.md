- **2026 광고주 목록이 MS 덱과 정확히 일치** → 이 폴더는 MS 덱 썸네일이 링크하는 **원본 저장소** = 덱과 중복, 별도 수집 불필요
- 예외: **2024 폴더 (~16개 파일)** 는 덱(2025 하반기~)에 없는 과거분 — 그립, 더한섬, 매일유업, 뮤직카우, 비즈넵, 빗썸, MLB + 비딩 6건
- 파일명 규칙: `광고주_소재명_사이즈.mp4` / 비딩건은 `비딩_광고주_...`

## 통합 방안 (Phase B 실행안)

1. **폴더 ⑤**: 2024 파일 16건만 신규 수집 (MS 소스로, year_month=2024 추정). 나머지는 덱과 중복 — 스킵
2. **폴더 ④**: 규모가 커서(84 광고주) 파일 전수 수집은 **Dropbox API 토큰** 필요
   - 권장: 드롭박스 앱 등록(무료) → scoped access token (sharing.read) → `/2/files/list_folder` 로 공유링크 전체 트리 1회 덤프
   - 대안: 담당자에게 폴더 zip 다운로드 요청 → 로컬 파싱 (파일명 규칙이 있어 메타데이터 손실 없음)
3. 파일명 파서: `^(\d{4})_([^_]+)_(.+?)(_\d+[x*]\d+)?\.(mp4|gif)$` → year_month/광고주/소재명/사이즈
4. 신규 광고주 ~49개 → 정기회의시트 재조회 + 제안값으로 마스터 확장
5. 웹 노출: video_url = 드롭박스 공유 파일 링크, 썸네일은 드롭박스 썸네일 API 또는 미생성(카드 플레이스홀더)
