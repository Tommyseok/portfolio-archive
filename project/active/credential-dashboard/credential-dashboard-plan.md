# 크리덴셜 대시보드 — 통합 계획 (Phase A)

- **승인일**: 2026-07-16
- **목표**: 부서별로 흩어진 제작물(PD/DS/MS 슬라이드 덱)을 하나의 아카이브로 통합하고, 정기회의시트 기준의 통일된 분류 체계 적용

## 분류 체계 (하이브리드 — 승인됨)

| 축 | 방식 | 정확도 |
|---|---|---|
| 고객사 | 슬라이드 파싱 | 정확 |
| 업종 분류 | 정기회의시트 캠페인탭 N열 → 광고주 마스터에서 자동 파생 | 정확 |
| 유형 분류 (브랜드/플랫폼) | 정기회의시트 캠페인탭 O열 → 자동 파생 | 정확 |
| 대분류 (소비재/금융·서비스/디지털·콘텐츠) | 업종에서 수식 매핑 (자동 롤업) | 정확 |
| 포맷 (촬영숏폼/스틸/AI영상 등) | 슬라이드 파싱 | 정확 |
| 제작방식·소스팀 (PD촬영/DS생성형AI/MS AI영상·모션) | 소스 덱에서 자동 유도 | 정확 |
| 소구포인트 | AI 분류 + 표본 검수 (폐쇄형 리스트, 주1+보조1) | 추정 (배지 표시) |

- 구 AE 라벨 스키마(campaign_objective/target_audience/visual_mood 등) 폐기
- 소구포인트 리스트: **사용자 수정 대기 중** (9개+기타 제안안에 수정 요청 있음)

## 단계

1. **광고주 마스터 동기화** — 캠페인시트 G(사업자명)/H(캠페인명)/N(업종)/O(유형) → `data/advertiser-master.json`. 시트에 없거나 업종 빈 광고주는 제안값 + 검수 플래그
2. **멀티소스 파싱** — DS덱(362장)·MS덱(78장) 구조 스파이크 → 파서 확장, `source_team`·`production_type` 필드 추가
3. **소구포인트 AI 분류** — 전체 항목, 확정된 리스트 기준
4. **대시보드 UI 개편** — 필터: 대분류→업종 / 유형 / 제작방식 / 소스팀 / 소구포인트 / 고객사
5. **배포 + 검수 보고**
